# AI Security Lab

## Overview

This repository documents an AI Security hands-on learning and lab exercise focused on protecting AI applications, AI agents, identities, APIs, sensitive data, and cloud environments.

The lab covers AI security posture management, identity and access control, API security, data protection, prompt security, threat detection, security alerts, attack path analysis, incident investigation, and risk-based protection.

---

## Objectives

The main objectives of this lab are:

- Understand AI Security fundamentals
- Understand the AI security attack surface
- Identify AI resources and dependencies
- Understand AI Security Posture
- Implement Identity and Access Control
- Apply Least Privilege
- Understand AI Agent Identity
- Secure APIs used by AI applications
- Understand Azure API Management
- Protect sensitive and confidential data
- Understand Prompt Injection and Prompt Security
- Understand Prompt Shield concepts
- Detect suspicious AI activities
- Generate and analyze security alerts
- Understand Attack Path Analysis
- Investigate AI-related security incidents
- Apply risk-based security controls
- Monitor AI environments continuously
