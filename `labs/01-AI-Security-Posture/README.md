
# Lab 01 – AI Security Posture

## Objective

Assess the security posture of the Azure environment and identify available security recommendations and risks.

---

## Requirements

- Azure account
- Active Azure subscription
- Appropriate permissions
- Microsoft Defender for Cloud access

---

## Steps

1. Sign in to Azure Portal.
2. Search for Microsoft Defender for Cloud.
3. Open Defender for Cloud.
4. Review the security posture.
5. Review available recommendations.
6. Identify security issues.
7. Review risk information.
8. Document the findings.

---

## Expected Evidence

Capture screenshots of:

- Defender for Cloud overview
- Security posture
- Security recommendations
- Relevant security findings

---

## Result

Document the security risks and recommendations identified in the environment.
