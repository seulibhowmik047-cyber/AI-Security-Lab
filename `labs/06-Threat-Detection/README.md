
# Lab 06 – AI Threat Detection and Investigation

## Objective

Detect suspicious AI-related activity and understand the investigation process.

---

## Steps

1. Monitor AI-related activity.
2. Identify unusual behavior.
3. Review available security alerts.
4. Identify the affected identity.
5. Identify the AI application or agent.
6. Identify API activity.
7. Identify affected resources.
8. Determine whether sensitive data was accessed.
9. Assess the risk.
10. Investigate the incident.
11. Apply an appropriate response.
12. Continue monitoring.
